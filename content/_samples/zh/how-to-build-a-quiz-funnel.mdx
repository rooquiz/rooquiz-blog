测评漏斗不是「测评题 + 末尾挂个表单」。它是依次给出的三个承诺，而绝大多数漏斗坏在第二个承诺缺席。

## 三个承诺

1. **钩子承诺** —— 标题告诉对方，他将了解到自己的什么。
2. **结果承诺** —— 结果页告诉他一件他自己猜不到的事。
3. **下一步承诺** —— 后续动作，恰好补上结果暴露出来的那个缺口。

> 如果你的结果页换到另一个测评里也毫无违和，那你就没有结果承诺。

## 漏在哪里

| 环节 | 常见流失 | 通常原因 |
| --- | --- | --- |
| 进入 → 第 1 题 | 20–30% | 标题承诺了一个分类，而不是一个洞察 |
| 第 1 题 → 最后一题 | 15–25% | 题目太多，且没有进度提示 |
| 结果 → CTA | 50%+ | 结果泛泛，后续动作又和它无关 |

钱几乎全漏在最后一行。结果写着「你是均衡型规划者！」，接着推一份通用订阅——这条链就断了。

## 一种可落地的结构

```ts
// 每个结果分支都绑定一个具体的下一步，避免结果页变成死胡同
const outcomes = {
  overplanner: { gap: 'shipping', cta: 'the 7-day launch sprint' },
  underplanner: { gap: 'structure', cta: 'the one-page plan template' },
}
```

先定缺口，再从缺口倒着写结果文案。测评存在的意义，就是换取「指出这个缺口」的资格。

## 该看哪些数

- 完成率，按流量来源拆分
- 结果页 CTA 点击率，**按结果分支拆分**
- 首封跟进邮件的回复率

第二项是诊断指标。如果一个分支转化 12%、另一个只有 2%，问题出在某一屏文案上，而不是整个漏斗。
